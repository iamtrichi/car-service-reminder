<en-US>
🚗 V1.42 Release
Features included in this release:
• Added fuel usage and expense tracking per vehicle with L/100km consumption
• Added overall expense statistics with monthly spending charts
• Added vehicle document renewal tracking with expiry alerts
• Added per-vehicle expense breakdown by category
• Added settings page with searchable currency picker (all world currencies)
• Auto-detects device currency by timezone (e.g. Tunisia → TND)
• Added language flags next to the language selector
• Added live input updates when typing service costs
• Added edit/delete for logged service records in History tab
• Fixed engine variant data across 32 car brands (Renault, Audi, BMW, Ford, Toyota, and more)
• Resolved "Engine variant not found" error when adding certain vehicles
• Fixed overlapped Add button on the Dashboard
• Fixed Nissan (Micra) engine data
</en-US>
