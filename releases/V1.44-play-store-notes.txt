<en-US>
🚗 V1.44 Release
Features included in this release:
• Added searchable currency picker in Settings (filter by code, name, or symbol)
• Added automatic currency detection via timezone and IP geolocation
• Added edit and delete for logged service records in the History tab
• Added document renewal tracking — past costs are kept in expense history
• Added flag emojis to the language selector in the side menu
• Fixed fuel log modal layout (no longer cut off by navigation bar)
• Fixed hardware back button to dismiss modals and overlays before navigating
• Added quick-add buttons on the Documents and Fuel page toolbars
• Fixed mileage sync to be forward-only (never rolls back)
• Sorted fuel log by odometer descending (highest mileage first)
</en-US>
